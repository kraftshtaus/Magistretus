Magistretus is an in-development 2D fantasy kingdom-management and city-building game prototype written in C++ with raylib.

The project is a personal programming and game-development portfolio piece. Its main focus is building game systems in C++, organizing code into reusable modules, and iterating on a playable prototype.
Status: Work in progress (WIP). This repository contains an experimental development version, not a finished or polished game. Updates may be irregular.

Project overview
The codebase is organized around the following systems:

- Application and game states: application flow and switching between screens.

- World and terrain: tile-based world representation, terrain textures, and map-generation logic.

- Kingdom selection: kingdom definitions and data for different starting choices.

- Resource management: systems for tracking resources used by the kingdom.

- Save management: save data and multiple save slots.

- Localization: English and Russian text resources.

- User interface: main menu, settings, new-game screen, resource HUD, and an evolving sidebar.

These modules are part of an ongoing prototype; individual features may be incomplete or subject to change.
Tech stack
- Language: C++
- Framework: raylib
- Build configuration: Makefile
- Development environment: Visual Studio Code
- Version control: Git and GitHub
